## Toggle Switch Functions

- **Toggle Switch 1**
  - Left position: the input signal is mixed dry after the loop processing.
  - Center position: the input signal is mixed with the loops and processed through the same effects.

- **Toggle Switch 2**
  - Left position: reverse loop playback.
  - Center position: forward loop playback.
  - Right position: randomized loop speed playback.

- **Toggle Switch 3**
  - Left position: dynamic sampler mode.
  - Center position: looper mode.
  - Right position: reverb mode.
